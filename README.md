# VEGAS 章鱼（vegas-octopus）

独立的多品种实时行情与 Vegas 交易可视化项目。

## 项目目标
构建沉浸式科幻风格交易大屏，以真实行情、信号、交易和账户数据驱动画面。机械小章鱼与美元金币的动画必须和真实交易事件/盈亏状态关联，不得用虚构数据冒充真实交易结果。

## 项目文档
- [设计需求与视觉规范](docs/design-spec.md)
- [完整开发路线图](docs/roadmap.md)

## 首阶段范围
1. 多品种行情展示：为后续接入美股、BTC、HYPE、黄金、原油等数据预留适配层。
2. 信号与交易事件展示：展示上游 Vegas 系统提供的信号和交易事件；本项目不擅自修改 Vegas 交易规则。
3. 账户与收益：显示资金、持仓、盈亏和收益曲线；明确区分真实数据、模拟数据和连接状态。
4. 机械章鱼视觉：沉浸式暗色科幻界面，具有强烈生物感的机械章鱼在市场区域间游动，并响应真实事件。
5. 数据可靠性：行情过期、缺失或连接失败时明确标记，不将占位数据显示为实时数据。

## 架构边界
- 本仓库独立于现有 Vegas 信号、回测和交易系统。
- 前端展示层与行情/交易数据适配层分离。
- 初期只做监控和可视化；未获明确授权前，不接入自动下单，不改变交易规则。
- API 密钥、令牌和账户凭证不得提交到 Git 仓库；通过环境变量或安全的密钥管理方式配置。
